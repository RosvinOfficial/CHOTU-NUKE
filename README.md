## 🖥️ Overview

**CHOTU-NUKE** is a Python CLI for **Discord server administration** — providing channel and role management, member tools, server information, and moderation utilities through a Rich terminal interface.

**Authorized use only:** your own servers, test environments, or servers where you have explicit permission to run automation.

## 🚀 Installation

You can either download the repository as a ZIP file or clone it using Git.

### Option 1 — Download ZIP

1. Open the [CHOTU-NUKE GitHub repository](https://github.com/RosvinOfficial/CHOTU-NUKE).
2. Click **Code → Download ZIP**.
3. Extract the ZIP file.
4. Open the extracted **CHOTU-NUKE** folder.
5. Double-click **`python_installer.bat`**.
6. After it finishes, double-click **`setup.bat`**.
7. After setup completes, double-click **`start.bat`**.

### Option 2 — Clone the Repository

```bash
git clone https://github.com/RosvinOfficial/CHOTU-NUKE
cd CHOTU-NUKE
```

Then run the following files in order:

```text
1 — python_installer.bat     checks Python
2 — setup.bat                installs dependencies
3 — start.bat                launches the CLI
```

> **Windows:** The included `.bat` files automate the installation and startup process.

## 🔐 Security

**Never publish your Discord bot token.**

Keep credentials outside the repository using environment variables or another secure secret-management method.

Do **not** commit:

```text
.env
config.json
bot_token.txt
secrets.json
```

If a bot token is accidentally exposed, immediately regenerate it through the Discord Developer Portal.
